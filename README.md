Vice Sunset Cover Maker — an offline web app that turns your own photos and a caption into multi-panel GTA 6-style cover art: four layouts (Vice Poster, Triple Strip, Four Grid, Nine Grid), per-panel crop/zoom/position, four neon-sunset colour grades, film grain and vignette for a printed-poster finish, bold caption lettering, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080. Everything runs locally in the browser; photos are never uploaded. It ships with two sample photographs so the cover is photographic from the first load. All artwork is original — no Rockstar logo, artwork or font.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
